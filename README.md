# .github

Organization-wide defaults for [Macro Evidence](https://github.com/macro-evidence): the public organization profile (`profile/README.md`), Code of Conduct, Contributing guide, Security policy, and issue/PR templates.

Any repository in this organization that does not define its own copy of one of these files inherits the default here. Repositories that define their own take precedence — see [GitHub's documentation on default community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file) for the exact precedence rules.

## Contents

| File | Purpose |
|---|---|
| `profile/README.md` | Rendered as the organization's public profile README |
| `CODE_OF_CONDUCT.md` | Contributor Covenant 2.1, adapted |
| `CONTRIBUTING.md` | How issues and PRs are handled at this stage |
| `SECURITY.md` | Vulnerability reporting |
| `PULL_REQUEST_TEMPLATE.md` | Default PR template |
| `.github/ISSUE_TEMPLATE/` | Bug report and feature request forms, plus template chooser config |
| `assets/` | Logo, banner, and social preview image used above and by other repositories |

This repository must stay **public** — private `.github` repositories are not used for organization-wide defaults.
